## Описание

Лабораторная работа N2. Вариант 12.

Страница "О себе" оформлена внешним файлом style.css в серебристо-черной гамме.
Добавлены проверки валидности HTML и CSS через сайт https://validator.w3.org/. Ошибок нет.

### Реализовано

- Стили подключены тремя способами: основные во внешнем файле, inline-стиль у h1, одно правило во внутреннем style.
- CSS-переменные в :root: серебристый основной цвет, черный акцент.
- Позиционирование: static у h2, relative у сетки навыков, absolute у бейджа.
- Состояния: hover и active на карточках навыков, focus и active на кнопке, hover и visited на ссылках.
- Контраст текста примерно 8:1.
